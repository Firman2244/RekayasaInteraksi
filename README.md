# Rekayasa Interaksi (UX) - Top-up E-Wallet Mobile Banking

Proyek mata kuliah Rekayasa Interaksi (UX) oleh Firman Maulana Bhagaskara (202310370311355).

Fitur: top-up e-wallet dari rekening bank di aplikasi mobile banking. Fokus: menampilkan saldo yang bisa digunakan, memperingatkan pengguna sebelum PIN, dan memberi kepastian status dana saat top-up gagal.
